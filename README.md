# coding-style

A coding style guide for AI coding agents: general principles for any language, plus TypeScript and React. Your project's own conventions always win, and rules marked *(opinion)* are preferences you can drop.

Start with [the rules in one screen](skills/coding-style/SKILL.md#the-rules-in-one-screen).

## Install

In Claude Code:

```
/plugin marketplace add hevele-moda/coding-style
/plugin install coding-style@coding-style
```

To share it with everyone working in a repo, run `claude plugin install coding-style@coding-style --scope project` and commit `.claude/settings.json`.
